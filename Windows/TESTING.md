# Windows 验证

纯逻辑检查可在 macOS / Windows / Linux 运行，不需要测试框架依赖：

```sh
dotnet run --project Windows/Tests/CoreTests.csproj -c Release
```

Windows 上还可验证完整发布包里的所有表情能否被系统图片解码器加载。此检查不安装全局按键监听、不打开轮盘、不修改设置：

```powershell
$result = Start-Process .\dist\EmoteWheel-windows-x64\EmoteWheel.exe -ArgumentList '--self-test' -Wait -PassThru
if ($result.ExitCode -ne 0) { throw 'EmoteWheel image smoke test failed' }
```

跨平台编译不能代替下面的 Windows 桌面实测。首次使用请确认这些交互：

| 场景 | 预期 |
| --- | --- |
| 浏览器页面空白处、普通按钮、桌面 | 按住 Y 显示轮盘；向八个方向移动并松开，展示对应图片 |
| 鼠标留在圆心 | 松开 Y 不展示图片 |
| 记事本 / 浏览器输入框 / 聊天编辑框，英文输入 | 按 Y、连续输入、长按 Y 都正常输入，不出现轮盘 |
| 同样的输入框，中文输入法拼音与候选窗口 | 输入含 y 的拼音时不出现轮盘 |
| 网页可选中文字、非编辑的文章区域 | 不会仅因支持文字选择而屏蔽轮盘 |
| 按住 Y 时 Esc、鼠标右键、切换前台应用 | 取消轮盘 |
| 设为 Ctrl + Y | 按住组合键可展示；先松 Ctrl 再松 Y 取消；中途多按 Shift 也取消 |
| 连续快速按下 / 松开快捷键 | 不出现延迟弹出的轮盘 |
| 两台显示器，含不同缩放比例和左侧负坐标 | 轮盘出现在鼠标所在屏幕；边缘不被切掉；上下左右方向正确 |
| 搜索“弱爆”、“流汗”、英文名、ID 3239 | 可找到对应表情并替换选中槽位 |
| 导入本地 PNG / JPEG，重启程序 | 自定义表情和轮盘装配保留 |
| 关闭设置 | 应用留在托盘，快捷键仍可用；双击托盘重开设置；菜单“退出”完全退出 |

输入保护读取 UI Automation 的控件类型和可编辑属性，不读取或保存用户输入。未暴露可编辑信息的自绘编辑器仍需要兼容性验证。普通权限运行时，管理员窗口、锁屏、安全桌面和部分独占全屏应用可能无法监听或覆盖；优先使用普通桌面窗口或无边框窗口进行验证。

程序不会屏蔽 Y 的原始按键，也不会向游戏或聊天应用发送内容。需要避免目标应用原有快捷键冲突时，可在设置中换成其他键或组合键。
